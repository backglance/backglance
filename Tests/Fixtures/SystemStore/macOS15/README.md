# macOS 15 store fixture

Generated by `Scripts/make_fixture.sh` (which shells out to the `FixtureGenerator`
executable target) and verified by `Scripts/verify_fixture.sh`. Lands in Phase 1.8.

Every value here is **synthetic**: app bundle IDs, titles, bodies and one-time codes all
come from a seeded `SplitMix64`, so a fixture is reproducible and contains no personal
data. Never copy a real `~/Library/Group Containers/group.com.apple.usernoted` store into
this directory — the pre-commit hook refuses anything that looks like one.

Expected contents once Phase 1.8 ships: `store.db`, `manifest.json`, `expected.json`.
